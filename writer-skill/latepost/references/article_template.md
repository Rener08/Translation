# 公众号文章改写模板（基于内容方法论 + 风格示例 + SKILL）

## 1. 开头破题（1-2段）
- 从一个具体、当下、可感知的场景切入，不做宏大叙事。
- 第一段就制造“然后呢”的阅读驱动力。
- 语气口语化，可带轻微自我暴露或真实反应。

可用开头句式：
- 故事是这样的。
- 这两天我碰到一件很离谱的事。
- 先说结论，这事跟我想的完全不一样。

## 2. 问题定义与背景铺垫（1-2段）
- 清楚说出这篇文章要回答的问题。
- 交代必要背景，但不要教科书式展开。
- 始终围绕主线，不要离题堆信息。

推荐结构：
- 现象是什么
- 为什么值得聊
- 今天准备怎么拆开看

## 3. 核心展开（3-5段）
- 每段只讲一个重点，结构保持“观点 -> 例子 -> 解释 -> 回扣主线”。
- 尽量使用“亲自下场 / 真实案例 / 逐一展示”的写法。
- 可以插入知识点，但要“聊着聊着顺手掏出来”，不要生硬科普。
- 保留原始事实与顺序，不新增原文没有的关键结论。

推荐段落写法：
1. 观点句：先给出判断
2. 证据句：给具体例子或片段
3. 解释句：说清背后的原因
4. 扣主线句：拉回本文核心问题

## 4. 节奏与风格要求（贯穿全文）
- 句式长短交替，允许短句独立成段制造停顿。
- 转场自然口语化，比如“回到这块”“顺着上面继续聊”。
- 保持“活人感”，允许有限自嘲、疑问句、感叹句，但不过量。
- 避免AI腔套话：首先/其次/综上所述/值得注意的是/说白了/本质上。

## 5. 升维与收束（1-2段）
- 在不偏离主线的前提下，提炼更高层启发（方法、认知或判断框架）。
- 不是喊口号，而是把读者带到“所以我接下来可以怎么做”。

## 6. 结尾（1段）
- 回扣开头提出的问题或场景。
- 给一个清晰、可执行、不过度夸张的收尾。
- 语气真诚、克制，不端着。

---

输出要求：
- 只输出正文，不输出分析过程和提示词解释。
- 按上述模板自然组织文章，不必机械写小标题。
- 信息不足处可简洁过渡，不允许编造事实。
