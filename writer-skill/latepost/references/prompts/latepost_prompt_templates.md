# 晚点 Prompt 模板索引（3 类主表）

这个文件现在只做索引，不再放完整模板。

晚点的主基调是第三视角、冷静客观、信息密度高的深度报道口吻。
正文篇幅按原文长度做软控制，尽量落在 40% - 65% 区间，不再写成硬字数门槛。
段落标题长度规则单独看 `11_section_titles_and_reverse_prompt.md`，不要和正文篇幅混为一条规则。
第三视角不是把人称改成“他/她”，而是把正文主语放在事件、变化、机制和边界上。

默认主表只保留 3 类：
- `09_interview_transcript_sync`：访谈 / 播客 / 字幕同步稿
- `03_product_review`：产品 / 实测 / 评测
- `06_infra_cloud_model_platform`：基础设施 / 云 / 模型 / 平台

`01_big_company_war` 只作为窄兜底；其余模板仅做扩展参考。

- `../extended/README.md`：扩展参考索引

## 使用方式
- 优先打开一页版直接复制
- 如果题材明显落在主表之外，再考虑扩展参考
- 把 `{}` 或 `[在这里贴入素材]` 替换成你的输入
- 如果题材不确定，优先选最接近主矛盾的主表类目
