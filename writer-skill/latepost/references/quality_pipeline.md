# 晚点写作四层质检

这份文件给出一套可执行的分层质检流程。目标是：在不牺牲晚点口吻的前提下，稳定提高文章可信度、可读性和判断质量。

## L1 硬约束检查（不通过就重写）

- 第三视角是否稳定（第一人称应为 0）？更重要的是，叙述主语是否是事件、变化和机制，而不是人物发言顺序？
- 是否出现补造数字、补造引语、补造事实？
- 篇幅是否大致落在原文长度的 40% - 65% 区间内？这条只做软提示，不作为硬失败条件。
- 开篇 1-2 句是否包含“判断 + 可核实事实锚点”？
- 是否至少包含：事实点 >= 5、机制段 >= 1、代价或边界段 >= 1？
- 正文是否被写成提纲或口号堆砌？

## L2 风格一致性检查（晚点口吻）

- 主语是否具体到公司、产品、组织、人物、系统？
- 段落衔接是否自然，有没有机械模板痕迹？
- “不是 A，而是 B”是否过量使用？
- 连接词是否重复轰炸（例如“这意味着”连续出现）？
- 是否始终围绕一个主矛盾推进？

## L3 内容深度检查（信息密度）

- 判断是否紧贴事实，而不是空降结论？
- 机制解释是否清楚（为什么发生、如何发生）？
- 是否给出替代路径、对比样本或反例？
- 是否写出代价、边界和下一层问题？
- 是否标出不确定信息（待核实），而不是强行确定？

## L4 终审（读者体验）

- 通读一遍，第一段是否足够抓人？
- 中段是否有节奏断裂或离题漂移？
- 结尾是否形成收束，而不是再开新题？
- 全文是否像“懂行业的人在写报道”，而不是“模型在拼模板”？

## L5 多轮校准（测试→回改→再测）

当需要把输出逼近晚点感时，用固定闭环，而不是只改规则：
1. 先用当前 skill 写一版样稿，尽量完整保留开头 / 中段 / 结尾
2. 只看三类偏差：开头是否判断太早、段落是否概念先行、收尾是否总结过满
3. 优先改“判断时机”和“段落推进方式”，不要先从词表下手
4. 重点回改三处：开头先钉具体变化；中段先写动作、变化、限制，再写解释；结尾回收前文具体事实
5. 用同一素材再测一轮，对比“现场感、自然停顿、事实摩擦”是否增强

## 建议输出格式

交付前给一段简短质检结论：

```text
质检结论：
- L1：通过 / 未通过（问题：...）
- L2：通过 / 未通过（问题：...）
- L3：通过 / 未通过（问题：...）
- L4：通过 / 未通过（问题：...）
- 处理动作：重写了哪些段落，为什么
```
