# 晚点长文路由

这个 skill 负责把素材路由到合适的长文模板。

它的关注点不是个人口吻，而是：

- 判断题材类型
- 选择场景模板
- 保持第三视角叙述
- 让长文结构稳定、克制、信息密度足够

晚点的主基调是第三视角、冷静客观、信息密度高的深度报道口吻。

当素材明显是访谈、产品评测、行业落地、基础设施、融资或风险主题时，优先按这里的模板处理。

详细模板、配置和 prompt 索引都放在 `references/` 里。默认可见面只保留 3 类主场景：访谈同步、产品实测、基础设施 / 云 / 模型 / 平台；其他题材只作为窄兜底或扩展参考。

`references/style_examples.md` 是晚点版的写法示例库，结构上对齐卡兹克，但内容只保留第三视角、冷静客观、深度报道风格。

它通常会和 `kazix` skill 搭配使用，前者负责长文路由与模板组织，后者负责风格和写作规则。
