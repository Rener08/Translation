# Code of Conduct

This project is intended to be a respectful, collaborative space.

## Our Standards

Please:

- Be courteous and constructive.
- Assume good intent unless there is clear evidence otherwise.
- Keep feedback focused on the work, not the person.
- Make room for questions, corrections, and learning.

Please do not:

- Harass, insult, or intimidate anyone.
- Make discriminatory comments or jokes.
- Post sexual, violent, or otherwise abusive content.
- Deliberately derail issue threads or pull requests.

## Scope

This code of conduct applies to project issues, pull requests, reviews,
comments, discussions, and any other project-maintained collaboration space.

## Enforcement

Maintainers may remove content, issue warnings, or limit participation when
behavior harms the community or repeatedly violates these expectations.

## Reporting

If something feels inappropriate or unsafe, please report it to the project
maintainer through a private channel or a private GitHub message if available.
Reports should include the relevant context and links when possible.

## Attribution

This code of conduct is a lightweight project policy inspired by common open
source collaboration norms. It is meant to be practical and easy to follow.
