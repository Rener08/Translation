# 晚点 Prompt 一页极简版（8 类）

> 直接复制就能用。每类只保留 3 行：用途、要求、结尾方向。

## 1）巨头战役 / 组织重排
把素材写成晚点式大厂战役稿。要求：第三视角、冷静克制；先钉具体变化，再自然给判断；重点写组织、资源、入口、节奏如何重排。标题要有主体、变化和判断。

## 2）人物 / 组织 / 风波
把素材写成晚点式人物风波稿。要求：先写发生了什么，再写为什么重要；不写八卦，写成组织问题；把分歧、取舍、不确定性写出来。结尾回到权力和再分配。

## 3）产品 / 实测 / 评测
把素材写成晚点式产品实测稿。要求：先写一个真实任务，最好带人物、动作、场景或时间；写清执行过程、纠错过程、失败点；对比演示效果和真实可用性。结尾落到产品边界和形态变化。

## 4）行业落地 / 场景改造
把素材写成晚点式行业落地稿。要求：先写旧流程和老问题；再写技术具体嵌入在哪一环；重点写省了哪些事，而不是技术多强。结尾落到代价、边界和下一层问题。

## 5）硬件 / 机器人 / 制造 / 终端
把素材写成晚点式硬件稿。要求：先写产品形态和场景；再写供应链、工程、成本、体验、量产；对比旧方案和新方案。结尾落到产品边界和产业后果。

## 6）基础设施 / 云 / 模型 / 平台
把素材写成晚点式基础设施稿。要求：先给拐点或规模数字；解释为什么竞争从单点能力变成全栈能力；写清资源、算力、数据、平台、商业化关系。结尾用代价、边界、长期主义收束。

## 7）创业 / 融资 / 估值 / 路径对比
把素材写成晚点式创业融资稿。要求：先写钱、估值、融资、IPO、投资人这些硬信息；再写公司为什么选这条路线；再写代价和共同难题。结尾写“接下来还要面对什么”。

## 8）风险 / 泡沫 / 对齐 / 事故
把素材写成晚点式风险稿。要求：用一个具体事故或数据开场；迅速放大到行业级风险；写清机制：权限、数据、激励、路径、泡沫循环。结尾写怎么避免下一次。

## 段落标题统一规则
- 如果需要小标题，段落标题控制在 15 字以内，优先 4-10 字
- 标题只写一个点，不写完整句
- 优先用“主体 + 变化”“问题 + 代价”“现象 + 机制”

## 总提示词
用晚点 LatePost 的中文深度报道口吻写作：第三视角、冷静克制、连贯叙事；先钉具体变化，再自然给判断；先写变化，再写机制；多用具体人名、公司名、产品名、时间、数字；少空话、少口号、少概念堆砌；像记者写报道，而不是像宣传稿。

## 反向提示词
不要写成通稿、空话总结、官方宣传、纯抽象分析、术语堆砌、时间线流水账；不要让段落标题超过 15 字，不要把小标题写成完整句子或口号；不要只讲结果不讲机制，不要只讲观点不讲证据。
