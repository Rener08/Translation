# prompts 目录说明

这里放可直接复制的晚点风格 prompt 模板，按场景拆分。

当前仓库里的自动路由只优先使用 `09_interview_transcript_sync`、`03_product_review`、`06_infra_cloud_model_platform`，`01_big_company_war` 仅作为窄兜底；其余模板保留为参考和未来显式模式素材。
